# CompareDiff

面向计算机视觉科研实验结果的图像可视化对比工具。

在计算机视觉研究中，无论是寻找创新点还是验证模型效果，定量指标都只能描述结果的一部分。最终的判断往往仍需要回到可视化结果：模型在哪里改善了细节，在哪里引入了伪影，失败案例是否具有一致的模式。

通用图像对比软件通常更适合逐张文件的人工选择，缺少对科研实验目录结构的理解。当一个实验同时产出大量结果图，并且需要与对应的 Ground Truth（GT）或基线结果逐一核对时，手工定位配对文件会打断分析过程。CompareDiff 同时支持自由选择单对图像与面向实验目录的批量浏览：自动发现同相对路径的图像对，并在自动匹配不满足需求时允许研究者手动指定任意两张图像。

## 当前状态

当前版本是一个可用的单对/文件夹图像配对与可视化浏览工具，核心入口为 `compare_tool.py`，并已通过 `ImageCompareTool.spec` 打包为 Windows GUI 程序。

它目前聚焦于“找到适合比较的图像对，并方便地做人工视觉检查”。它不是指标计算、统计汇总或自动生成实验报告工具；这些能力仍属于后续可扩展方向。

## 已实现功能

- 提供两种图像对比模式：`文件夹对比`（默认）和 `单对图片`。
- 单对图片模式可自由选择任意左图 Result (A) 与右图 GT (B) 后立即对比。
- 文件夹模式可选择 `Result (A)` 和 `GT (B)` 两个根目录。
- 递归扫描 Result 目录，按**相对路径和文件名完全一致**的默认规则查找 GT 中的对应图像。
- 在“自动匹配”列表中显示所有成功配对的文件，点击即可切换。
- 自动匹配为零时自动切换到“手动配对”；存在自动匹配时也可手动切换到该视图。
- 手动配对视图将目录内的图像分为左右两列，用户可任选一张左图和一张右图进行比较。
- 当前选中的左图和右图文件名会显示在顶部目录选择栏；完整路径可通过悬停查看。
- 文件列表优先显示文件名；父目录层级过长时压缩为 `..\..\文件名`，完整相对路径可通过悬停查看。
- 支持 PNG、JPG/JPEG、BMP、TIF/TIFF 图像；可读取包含中文字符的路径。
- 对图片读取失败、尺寸不一致和通道格式不兼容给出提示，不加载无法进行像素级比较的图像对。
- 使用可拖动的竖直分割线对比左侧 Result 与右侧 GT。
- 提供绝对差分（Diff）视图，并对差分进行 3 倍增强，便于观察微小变化。
- 支持滚轮缩放、鼠标拖拽平移，以及“适配窗口”复位视图。
- 鼠标悬停时显示当前像素坐标、当前侧的像素值，以及 Result 与 GT 的像素差值。

## 目录约定

两个目录应具有一致的相对路径结构。例如：

```text
experiment_result/
  scene_001/
    slice_0001.png
  scene_002/
    projection.tif

ground_truth/
  scene_001/
    slice_0001.png
  scene_002/
    projection.tif
```

上述结构会匹配出两对图像。只存在于其中一个目录的图像不会进入对比列表。

为保证分割对比和差分计算的结果正确，每一对图像应具有相同的宽高；建议也保持相同的图像类型与通道语义。

## 使用方法

### 直接运行源码

安装依赖：

```powershell
python -m pip install PyQt5 opencv-python numpy
```

启动应用：

```powershell
python compare_tool.py
```

启动后可通过顶部“对比模式”选择工作流：

1. `文件夹对比`（默认）：依次选择 Result (A) 和 GT (B) 目录。扫描完成后会显示自动匹配数量和文件列表。
2. `单对图片`：分别选择左图 Result (A) 与右图 GT (B)，选齐后立即显示对比结果。

在文件夹模式中，若没有同相对路径的图像，程序会自动打开“手动配对”视图；也可以主动切换到该视图，从左右两列中选择任意图像进行比较。

### 使用已打包程序

若本地存在打包产物，可直接运行：

```text
dist/ImageCompareTool.exe
```

### 重新打包 Windows 程序

安装 PyInstaller 后，使用项目中的打包配置：

```powershell
python -m pip install pyinstaller
pyinstaller ImageCompareTool.spec
```

默认产物为 `dist/ImageCompareTool.exe`。

## 交互方式

| 操作 | 效果 |
| --- | --- |
| 在顶部切换对比模式 | 在文件夹批量浏览与任意单对图片比较之间切换 |
| 点击自动匹配列表 | 打开对应的 Result / GT 图像对 |
| 在手动配对两列中各选择一张图，再点击“对比所选图片” | 打开任选的左右图像对 |
| 悬停文件名 | 查看完整相对路径或完整文件路径 |
| 拖动黄色分割线 | 改变 Result 与 GT 的显示边界 |
| 在非分割线区域按住左键拖动 | 平移图像 |
| 鼠标滚轮 | 缩放图像 |
| `适配窗口 (Fit)` | 以合适比例居中显示当前图像 |
| `切换 Diff 模式` | 显示 Result 与 GT 的增强绝对差分 |
| 鼠标悬停在图像上 | 查看坐标、像素值和像素差 |

## 技术栈

- Python
- PyQt5：桌面图形界面
- OpenCV：图像读取、转换与差分计算
- NumPy：图像数组处理
- PyInstaller：Windows 可执行文件打包

## 后续方向

本项目的目标是让实验结果的视觉验证更连续、更适合批量科研工作流。后续可以围绕以下方向继续完善：

- 配对缺失、尺寸不一致和读取失败的可见报告
- 按文件名规则、后缀映射或自定义清单进行匹配
- 多方法、多列结果的同步对比
- 图像叠加、闪烁切换、透明度混合与局部放大镜
- 对比结论、失败案例和截图的标注与导出
- 与 PSNR、SSIM、LPIPS 等指标文件关联，形成指标与可视化的联合筛选
